# Mi Rutina

Guía visual de entrenamiento en español. La programación semanal usa la hora de Colombia.

- `npm install` instala las dependencias.
- `npm run dev` abre el servidor local.
- `npm run build` comprueba TypeScript y genera el sitio estático en `dist/`.
